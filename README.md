# 📝 React + Tailwind Todo App

This is a simple and clean Todo App built with **React** and styled using **Tailwind CSS**. Built collaboratively with the help of **ChatGPT** and **GitHub Copilot**, it demonstrates the power of combining modern developer tools and AI-assisted coding.

---

## ✨ Features

- CRUD todos
- Minimal and responsive UI using Tailwind CSS
- Built with functional components and React Hooks
